        Skills and setup

        Three skills share the style library above. A one-time setup gets each computer ready.

        video-editing

        Transcript-driven cuts with ffmpeg: silence and filler removal, punch-in zooms, audio cleanup, color, styled caption burn-in and platform exports. Ships three scripts.

        motion-graphics

        The 24 templates on this page, animation principles, preset-driven captions and a validation checklist. Checks the library before writing anything new.

        explainer-videos

        Script, storyboard, voiceover timing and scene-by-scene rendering in a design style, with cost checks before paid generation.

        Get started

        1. Install the plugin in Claude Code:
          /plugin marketplace add triftan/video-studio
/plugin install video-studio@video-studio
        2. Restart Claude Code, then run the one-time setup:
          /video-studio:setup
          It checks ffmpeg, Node and Python, prepares a Remotion workspace in ~/video-studio, and opens this catalog.
        3. Sign in to Fish Audio when setup asks: run /mcp, pick fish-audio, and log in with a free Fish Audio account. The connector ships with the plugin; no API key needed.
        4. Ask for a video. For example: "Make a 30-second 9:16 explainer about photosynthesis in the edu-chalk style with Fish voice Ethan."

        Open this catalog again any time with /video-studio:catalog.

        Part of the video-studio plugin for Claude Code. Rebuild this page with python3 catalog/build_catalog.py after changing the styles.
